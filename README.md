## How it works

`main.ts` (Node 22) writes exactly that one line — 80 characters, no trailing
newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
